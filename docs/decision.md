# 意思決定の記録（decision log）

> この記録は、前身の版（旧名 Engawa の `src/`・`public/kochira/`）で試したときのものです。提出版では、料金の守りを `盆栽マッチング_箱崎の試作/盆栽マッチング_動く試作_2026-11-05/盆栽ゴー_料金の守り.mjs` に引き継いでいます。


Engawa は、海外の愛好家の相談を、日本の職人の言葉で届け、職人の答えを意味で訳して返す、スマホ向けのサービスです。
最初から、この形だったわけではありません。
1週間で何を試し、何を学び、何を捨てたかを、日付つきで残します。

この記録の読み方：上の表で流れをつかみ、下の「Claude と一緒に決めた場面」で、判断が変わった根拠を見てください。

## Claude と一緒に決めた場面

### 1. 本物の Claude の応答で撮り直したら、聞き返しが指摘になった（2026-11-04）
- 最初のデモ動画（v0）は、AI の応答が見本のままだった。審査の物差しで採点すると59点だった（インパクト23・デモ15・Claude の活用7・深さ14）
- いちばん効く直しは「本物の Claude の応答で撮り直す」こと、と検品の結果に出た。上限金額を決め、手元の試験用サーバーだけでキーを使って撮り直した
- 本物の Claude は、相談の写真を「3D の絵に見える。本物の写真で確かめたい」と聞き返した。期間中に作った絵なので、正しい指摘だった
- 英語の手紙は「move it under the eaves」になった。ここで、方言の「なおす」が機械翻訳で "repair" になる問題を、用語集で意味に訳して直す設計を確かめられた

### 2. 調べ役のエージェントの結果で、機能を削った（2026-11-04 夜）
- 共同制作者が Managed Agents の Deep Researcher で「使う人の欲求と便益」を調べた
- 結論は「職人は、いまの設計では使わない見込みが高い。なぜ答えるのか、の理由が無い」
- Claude Code は先行例（BONSAI JOURNEY の「Letters」）のページを実際に開いて、実在を確かめた。違いは「スタッフが訳して何日も待つ」所だった
- 採った手：削る機能は画面から外す、「弟子が下書き → 親方が一言と印」にする、違いの1行を「待たない」にする

### 3. 検品役のエージェントが、点数と指摘で作り直しをさせた（2026-11-04〜06）
- 検品役は「Codex と Fable 5.1 の初回」と「Sonnet の2周目以降」で回し、90点まで直した
- 特集号デザインの版：81点 → 85点 → 86点 → 91点
- しぼった版：Codex 指摘5件（5件とも直した）、Fable 84点 → 88点 → 90点
- 庭の掲示板と市：Codex 10件。「写しを作る道具が、指定フォルダの中身を無条件に消していた」という重大な指摘が出て、目印のあるフォルダだけを作り直す形にした。3周で89点（決めた3周を使い切り、残りの減点を共有した）
- 点数が上がらなかった所も記録した。3周を使い切って90点に届かなかった件は、残りの減点の理由をつけて判断を仰いだ

### 4. 会議の文字起こしを全文読ませて、聞き違いまで直した（2026-11-05〜07）
- 文字起こしは、話し手の名前がすべて同じに出ていた。Claude に全文を3回読ませ、実際は3人だったことや、「凡災＝盆栽」などの聞き違いを直させた
- 「決まったこと」「出たアイデア（未決定）」「相手の問い」「宿題」に分けて記録し、決まっていないことを決まったことにしなかった
- 11/7 の職人への聞き取りと、そのあとの打ち合わせも同じ形で整理し、その日のうちに、アプリと動画を別々のセッションで並行して進めた

### 5. 作り話をしないために、数字と見本の文を原典に合わせた（2026-11-05〜07）
- 輸出額の数字は原典を確かめきれず、映す資料と口頭から外した
- 大宮の盆栽園の話は、出典の号が分からず外した
- 職人の答えの見本は、公開されている針金外しの手順（複数の専門家の解説）に合わせて直した。「絶対にほどかない」は言い過ぎだったので、「食い込んだ所は」と条件をつけた
- Claude の返事そのものにも同じ考え方を入れた。手紙の引用が本当に職人の言葉に含まれているかを、サーバーで照合する

### 6. 同じ作品を、アプリと動画で別のセッションが作った（2026-11-06〜07）
- アプリの作り直し、動画の絵コンテ、会議資料、受講した講義の回収を、別々のセッションで同時に進めた
- 動画の絵コンテは、検品で81点 → 85点 → 91点になった
- 並列にしたことで、動画の台本が古い案のまま残る、といったずれも起きた。HANDOFF に「古い案になった」と記録して、混ざらないようにした

## やらないこと（今回の範囲の外）
今回は、聞き取りでいちばん切実だった所にしぼりました。
「海外の人と、日本の職人が、言葉の壁を越えて、職人の都合のいい時間に答えられる」。ここだけを作り込みます。

- 木の輸出・配送・検疫の判断
- 決済・販売代行（売りたい木は、園の問い合わせ先を出して、つなぐだけ）
- 実際に SNS へ投稿すること（下書きと、職人の OK まで）
- 診断のような断定（写真の見立ては、職人の言葉からだけ出す。Claude が職人の代わりに答えない）
- 声や盆栽の写真を使った本人確認（盆栽が枯れたらログインできなくなるため）
- 期間より前に作ったものの流用
