# 盆栽マッチング（箱崎の試作・2026-11-05〜06）

Engawa とは別に、箱崎が Claude Code で作った試作です。Engawa のコード（`src/`・`public/` など）には触っていません。
中身は、ハッカソンの期間中（2026-11-05〜06）に作ったものだけです。

## 何ができるか
海外の愛好家が写真と母語で相談すると、職人には盆栽の日本語で届き、職人は話すか写真に線を引くだけで答えられます。答えは用語集を使った意訳で、相手の言葉になって届きます。
ほかに、写真からSNSの下書きを作る・話すだけで先生として登録する・職人を探す・職人に入るお金を見る・話すか撮るだけで木ごとに記録する、の画面があります。
名前・料金・相談の中身はすべてサンプルです。

## 動かし方
```bash
cd 盆栽マッチング_動く試作_2026-11-05
npm install
npm start
```
ブラウザで http://127.0.0.1:8787/index.html を開き、「アプリのホームを開く」から全部の画面に行けます。

- 端末に `ANTHROPIC_API_KEY` が入っていると、本物の Claude API で動き、料金がかかります。入っていなければ、記録しておいた見本の答えで動きます
- ログインはありません。だれでも全部の画面を開けて、相談の答えも上書きできます。公開する前に作る必要があります
