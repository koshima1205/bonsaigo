## 1. ログインで「見つかりません」と出る【解決】
- **起きたこと**：Mac の Chrome で、ログイン画面 → As a learner → 名前と English → Start を押すと、ボタンの下に「見つかりません」と出た。画面の下には「AI is not connected」と出ていた
- **原因**：11/6（金）22:40 に動かした古いサーバーが、8787番の入口を使ったまま残っていた。古いサーバーにはログインの仕組みがなく、`.env` も読まないため、AIも見本の答えのままだった
- **直し方**：古いサーバーを止めて（`kill` で止めた）、`npm start` で動かし直した。ログインできることを確かめた
- **防ぎ方**：3を見る

## 2. 相談を送ると「Couldn't send it」と出る【未解決】
- **起きたこと**：スマホから、海外の人として相談を送ると「Couldn't send it. Please wait a moment and press Send again.」と出て送れない（11/7 夕方）
- **原因**：まだ分からない。考えられるもの
  - 鍵が正しくない（文字が欠けている・余分なすき間がある）
  - Claude Console で支払いの設定がない、または残高が切れている
  - AIの呼び出し方（`サーバー.mjs` の `callClaudeApi`：モデル名・`betas`・`fallbacks`・`output_config`）が、今のAPIと合っていない
- **したこと**：失敗したわけを、サーバーのターミナルに出すようにした（鍵と相談の中身は出さない）
  - `[AIの失敗] 〜` … AIの呼び出しで失敗したとき
  - `[うまくいかなかった] POST /api/consultations → 〜` … 相談の受け付けで失敗したとき
- **次にすること**：サーバーを動かし直して、もう一度送る。出た1行を見て、原因を決めて直す

## 3. 古いサーバーが残っていても気づけない【未解決】
- **起きたこと**：古いサーバーが入口を使っていると、新しい `npm start` は動けずに止まる。それに気づけず、古いサーバーに向かって試していた
- **直し方の案**：
  - 起動のとき、入口がもう使われていたら「ほかのサーバーが動いています。止めてから動かしてください」と、はっきり出して止める
  - 画面の下か `/api/status` に、サーバーを起動した時刻を出す（古いサーバーかどうか見分けられる）

## 4. 相談の画面で、送れない本当の理由が出ない【未解決】
- **起きたこと**：03 は、AIの上限のとき以外、どんな失敗でも「送れませんでした。少し待って…」としか出さない。鍵の間違い・AIの不調・ログイン切れの区別がつかない
- **直し方の案**：失敗の種類ごとに、4言語の文を出し分ける（ログイン切れ／AIにつながらない／上限／そのほか）。合わせて8も直す

## 5. ログアウトすると、前の相談が見えなくなる【未解決】
- **起きたこと**：海外の人の印は、サーバーがくじ引きで作っている。ログアウトして入り直すと、別の人として扱われる
- **わけ**：前は名前から印を作っていたが、同じ名前の別の人に相談が見えてしまうため、安全の点検の指摘で変えた
- **直し方の案**：ログインに合言葉（パスワード）か、メールで届くリンクを入れる。6と一緒に考える

## 6. 職人のなりすまし【提出のあと】
- **起きたこと**：合言葉の内側なら、誰でも職人の一覧から選んで入れる。職人の登録（画面19）も、誰でもできる
- **直し方の案**：職人の登録のときに4けたの暗証番号を決め、ログインで入れる形にする
- 2026-11-07 に、提出のあとで直すと決めた

## 7. 学ぶ・用語集が、スペイン語・中国語で英語になる【未解決】

- **直し方の案**：スペイン語・中国語の文を足す。AIで下書きして、人が確かめる

## 8. サーバーのエラーの文が日本語だけ【未解決】

- **直し方の案**：サーバーはエラーの種類（記号）を返し、画面の側で4言語の文に置き換える
