# 盆栽ゴー（BONSAIGO）かずき版：引き継ぎ（2026-11-08 昼）

箱崎さんの版（このフォルダの `index.html`・`00〜22_*.html`・`ログイン_*.html`）と、かずき版（この `盆栽ゴー/` の1枚のアプリ）を、同じサーバーで並べて見られます。どちらを生かすかのすり合わせ用に、かずき版の中身と裏側のしくみをまとめました。

## 1. 動かし方（並べて見る）

```
cd 盆栽マッチング_箱崎の試作/盆栽マッチング_動く試作_2026-11-05
PORT=8801 BONSAI_DATA=/tmp/bonsaigo_data.json node サーバー.mjs
```

- 箱崎さん版：http://localhost:8801/
- かずき版：http://localhost:8801/盆栽ゴー/index.html（スマホ幅で見るのがおすすめ）
- 鍵を入れずに起動すると「見本モード」（AI を呼ばない・料金ゼロ）。見本の質問だけ、AI が答えたときの形を `盆栽ゴー_見本の答え.json` から見せます
- `BONSAI_DATA` は試しのデータの置き場。消せば最初の状態に戻ります

## 2. かずき版の画面（相談する人／職人）

| 側 | 画面 | できること |
|---|---|---|
| 共通 | はじめ | 相談する人／職人を選ぶ。右上で言葉を8つから選ぶ |
| 相談する人 | ホーム・聞く・園を選ぶ・送った・答え・Q&A（AI 窓口つき）・学ぶ（読みもの24本・動画・職人の声・言葉）・読みもの | 写真と自分の言葉で聞く。地域→樹種か悩み→答えられる園を縦に並べて選ぶ。Q&A の上の「たまった答えに聞く」で、これまでの答えから近いものを引ける（なければ「この問いを園に聞く」で聞く画面へ） |
| 職人 | 名前を選ぶ（園の名前が上→「◯◯園の◯◯さん」）・ホーム（おはようございます ◯◯ 様・答える言葉・投稿の件数）・相談の一覧・相談を読む・答えを書く・送る前の確かめ・木の登録（写真→下書き→確かめ→公開）・学ぶ（言葉の届き方・読みもの・動画・職人の声） | 自分の言葉で答える。お弟子さんも園の代わりに答えられる。学ぶの用語の訳を直す・読みものに気づきを足すと、相談する人の学ぶにすぐ出る（「◯◯が直しました」） |

入口のコピーは「盆栽の知恵を、世界へ。次の百年へ。」（8言語とも意味で訳した）。職人のホームに「あなたの手間は、写真と OK だけ」（発信は BONSAIGO が公式 X とインスタに）を出している。

職人の画面には、料金のしくみ・点数・モデル名・SAMPLE を出しません（かずきさんの指示）。

## 3. 言葉のしくみ（いちばん大事な所）

- 相談する人の言葉（`bg-l`）と、答える人の言葉（`bg-a`）を別々に持つ。職人は名前を選ぶと、その人の言葉になる
- **同じ言葉なら訳さずにそのまま届く**（AI を呼ばない）。違えば意味で訳し、逆に戻して確かめる
- 答えは「答えた人の言葉」で記録（`answer_lang`・`by`＝名前・役目・言葉）。相談した人の画面には、答えた人と園の名前の両方が出る
- 相談は「園」に届く（`garden_id`）。その園の人ならだれでも見て答えられる（園主・お弟子さん）。ほかの園からは見えない
- 画面の文字は `i18n.js`（8言語）。`{A}`＝相手の言葉の名前、`{G}`＝相談する人の言葉の名前、`{E}`＝園の名前。職人の画面（`.scr.k`）の中は、`g.` の鍵でも職人の言葉で出す

## 4. サーバー（サーバー.mjs）で増えた・変わった所

- 増えた API：`GET /api/bonsaigo/cost`（料金の守りの状態）・`GET/POST /api/bonsaigo/gloss`（用語の「直す／違うと知らせる」）・`GET /api/bonsaigo/qa`（Q&A 12件×8言語の検索）・`GET/POST /api/bonsaigo/trees`・`POST /api/bonsaigo/trees/:id/check`（木の登録→画像の確かめ→投稿の下書き→文の確かめ）
- 変わった API：`POST /api/consultations`（`garden_id`・`is_sample` を受け取る。同じ言葉なら AI なし）・`GET /api/consultations`（職人は自分の園の分だけ）・`POST /api/consultations/:id/answer`（園の確かめ・答えた人・答えた言葉）・`POST /api/login`（人を選ぶとその人の言葉に。新しく登録すると園も作る）・`GET /api/me`（園の一覧も返す）
- 架空の世界：`盆栽ゴー/data/world.json`（地域9・園9・人18・樹種・悩み・用語16語）。Q&A＝`data/qa.json`、読みもの＝`data/learn_a.json`・`learn_b.json`（24本×8言語・出典つき）
- 11/08 昼に足した API：`GET /api/bonsaigo/gloss` はだれでも読める（職人の直した訳＝用語×言葉ごとに最新1つ＋直した人）・`GET/POST /api/bonsaigo/notes`（職人が読みものに足した気づき＝`store.learn_notes`）・`POST /api/bonsaigo/window`（AI 窓口＝たまった Q&A から近い答えを3つまで。聞いた人の言葉で読める答えを先に。鍵がなくても動く）
- Q&A にたまる：答えのついた相談は、だれの相談でも Q&A に入る（相談した人の名前は出さない。聞く画面で「名前を出さずに Q&A にたまる」と知らせている）。`GET /api/bonsaigo/qa` は `pool`（たまった件数）も返す
- AI への指示：`盆栽ゴー_AIへの指示.mjs`（8言語の仕事の形・決まりの確かめ）
- 料金の守り：`盆栽ゴー_料金の守り.mjs`（確かめは Haiku・書くのは Sonnet・だめなときだけ Opus で1回・同じ頼みは前の答え・1人1日12回／全体200回）
- 箱崎さん版のログイン・本物の AI・安全の設定（`ACCESS_PASSWORD`・`AI_MODE`・`ANTHROPIC_API_KEY` など）はそのまま生きています

## 5. 画面の文字を直すとき

- かんたんな直し：`盆栽ゴー/i18n.js` を直接直してよい
- まとめて直す・言葉を足す：`盆栽ゴー/_言葉のもと/` で `python3 keys_1108b.py fix_1108b.json && python3 build_app.py`（`keys_1108b.py` に `k("鍵", 英, 日, 西, 中, 仏, 伊, タイ, クメール)` を足す）。同じ材料からは同じ `i18n.js` ができることを確かめ済み

## 6. 分かっていること・まだのこと

- タイ語・クメール語は機械の訳。母語の人の確認がまだ
- 写真は 3D と AI の絵、箱崎さんの大宮盆栽美術館の写真だけ。実在の園・人の名前は入れていない（園と人はすべて架空の見本）
- 園の名前が重ならないかの確かめは、まだ入れていない
- 見本モードでは、見本の質問以外は訳さない。人がためた Q&A は「相談した人の言葉」のまま出る（本物の AI なら訳を足せる）
- 本物の AI での通し確かめはまだ（見本モードで、8言語×29画面と、3つの流れ＝英語→日本の職人・日本語どうし・イタリア語→イタリアのお弟子さん、追加した機能 17画面を確かめ済み。スクショは `_スクショ_1108昼/`）
