# 3つの立場からの反論と、どう直したか（2026-11-07）

> この記録は、前身の版（旧名 Engawa の `src/`・`public/kochira/`）で試したときのものです。提出版では、料金の守りを `盆栽マッチング_箱崎の試作/盆栽マッチング_動く試作_2026-11-05/盆栽ゴー_料金の守り.mjs` に引き継いでいます。


Claude Code のサブエージェント3つを同時に動かし、それぞれ別の立場になって、スマホ版（`public/kochira/`）・動画の絵コンテ・提出の下書きに反論させました。
立場は「ある盆栽園の職人」「海外の愛好家（米国・歴6年）」「ハッカソンの審査員」の3つです。
指摘は全部で23件ありました。重い順に、直したもの・今夜決めるもの・今回はやらないものに分けています。

## 3つの立場に共通した指摘
- **職人の名前で、職人が言っていない言葉が届く**（職人1・愛好家1）
- **動画の画面が見本で、本物の Claude が出てこない**（審査員2・審査員1）
- **職人が使うには、手順がまだ長い**（職人2）

## 直したもの（このリポジトリで）
| 指摘 | だれ | 直したこと |
|---|---|---|
| 動画の画面のコードがリポジトリに無い（失格の恐れ） | 審査員 | スマホ版を `public/kochira/` に入れた。動画の画面はこのコード |
| 本物の Claude の応答が1回も出ない | 審査員 | 山場の4つ（相談を職人の言葉に・答えの案・声の直しを整える・意味で訳す）を `/api/kochira/*` で本物の Claude に。「本物の Claude で動かす」を入れると、画面の文が実際の応答に変わり、かかった秒数の札が出る（`src/kochira.ts`） |
| 説明は「Claude が答えの案を作る」、コードは「Claude は助言しない」で向きが逆 | 審査員 | 答えの案は、**園の手入れの記録だけから**作ることにした。どの文も、もとにした記録の番号を持つ。記録にない番号を挙げた文には「記録にない」の札が出る |
| AI の文が職人の名前で出る | 職人・愛好家 | 答えの画面を「checked and corrected by Kenji」に変えた。日本語の原文では、職人が声で直した文（緑）と、職人がそのまま通した文を分けて見せる |
| 作り話をさせない仕掛けが見えない | 審査員 | 英語の各段落に「元にした日本語の文」を返させ、職人の答えにそのままあるかをサーバーで照らし合わせる。合わなければ赤字で警告し、確認の画面に「引用の照合 OK／要確認あり」を出す |
| 方言を直訳すると意味が逆になる | 職人 | 用語集に「いけん（＝してはいけない）」「ええ（＝よい）」「針金外し」を足した（`src/glossary.ts`） |
