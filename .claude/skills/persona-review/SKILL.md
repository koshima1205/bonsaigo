# 3つの立場で反論させる

1. 見せるものを決める。スマホ版（`public/kochira/index.html`）・絵コンテ・動画のコマ・`docs/` の提出物など。
2. サブエージェント `persona-shokunin`・`persona-aikouka`・`persona-shinsain` を、**1つのメッセージで同時に**呼ぶ。どれにも同じ材料を渡す。
3. 返ってきた指摘を、次の3つに分ける。
   - **直す**：このリポジトリで直せるもの。直したら、どのファイルかを書く
   - **今夜決める**：人の判断や、ご本人の了承がいるもの
   - **やらない**：理由を1行つける
4. 2つ以上の立場が同じことを言ったら、「共通した指摘」として一番上に置く。
5. まとめを `docs/review_3personas.md` に、元の指摘を `docs/review_3personas/` に残す。決めたことが変わったら、`docs/decision.md` に1行足す。
