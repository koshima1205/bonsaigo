# 運用の料金と、下げる工夫（2026-11-07）

> この記録は、前身の版（旧名 Engawa の `src/`・`public/kochira/`）で試したときのものです。提出版では、料金の守りを `盆栽マッチング_箱崎の試作/盆栽マッチング_動く試作_2026-11-05/盆栽ゴー_料金の守り.mjs` に引き継いでいます。


Engawa を続けていくには、Claude API の料金を「精度が要る所だけ高いモデル」に絞る必要があります。
見積もりは `scripts/cost_estimate.py` で出しています（1ドル＝150円の仮置き。トークン数はプロンプトの長さからの見込み）。
キーを入れて動かすと、本当の料金が `/api/kochira/meter` に1日ごとにたまり、画面の札にも1回ごとの料金が出ます。見込みは、その値で置き換えます。

## 1件あたり
| 何 | 全部 Opus | 工夫あり |
|---|---|---|
| 相談1件（写真を読む → 答えの案 → 声の直し → 意味で訳す） | 約17円 | 約9円 |
| AI 窓口の質問1件（用語集と記事から答える） | 約4.4円 | 約0.04円 |
| 答え1件から記事（5つの言葉）とショート | 約26円 | 約6.5円（※Batch API は未実装） |

| 使われ方 | 相談 | 窓口の質問 | 記事 | 全部 Opus | 工夫あり |
|---|---|---|---|---|---|
| 少なめ（1人 相談1・質問3） | 100件 | 300件 | 30本 | 約3,800円 | 約1,000円 |
| ふつう（1人 相談3・質問10） | 300件 | 1,000件 | 90本 | 約11,800円 | 約3,000円 |

どの場合も、**約75%下がる**見込みです。サーバー（Cloudflare）の料金は、この規模なら無料の枠に収まる見込みで、ここには入れていません。

## 入れた工夫（`src/kochira.ts`・`src/index.ts`・`src/claude.ts`）
1. **決まりで済むことは AI を使わない**
   - 同じ入力には、前の答えを KV から返す（料金0円・画面の札に「再利用・0円」）
   - 用語の見つけ方は文字列で探す。英訳の引用の照合も、文字列で照らし合わせる
2. **判定役は Claude Haiku 5.5**（Opus の40分の1の値段）
   - 判断専用の AI（TypeSafe 社の Jev など）と同じ形で、「選んだ答え＋自信の度合い（0〜1）」を返させる。自信が0.8未満なら、安い答えは使わず安全な側（職人に回す・Opus で確かめる）に倒す
   - 相談が届いたら、まず「職人に回すものか／用語の意味を聞いているだけか／盆栽と関係ないか」を仕分ける。関係ないものは高いモデルに回さない。用語の質問は用語集から返す
   - 英訳ができたら、「訳し戻した文が、元の答えと同じ手入れの内容か」を判定する
3. **ふだんは Claude Sonnet 5.5 で作り、だめなときだけ Opus 5.5 に上げる**
   - 答えの案：記録にない番号を挙げた・迷った文が1つでない → Opus で作り直す
   - 英訳：引用の照合（決まり）か意味の判定（Haiku）が通らない → Opus で訳し直す
   - 上げ直したときは、画面の札に「Opus で確認」と出る
4. **プロンプトキャッシュ**
   - 用語集（約1,200トークン）と、窓口の記事（約5,000トークン）は毎回同じなので、キャッシュに載せる。2回目からは、その分の入力の料金が 0.05〜0.1 倍になる
5. **AI 窓口は Haiku に**
   - 答えは用語集と記事からだけ。自分の木の相談は職人に回す（`handoff`）
6. **上限**：1人1日12回・全体で1日200回（スマホ版）
7. **切り替え**：`KOCHIRA_MODE=quality` にすると、全部 Opus に戻る（見比べ用）

## これから
- 記事の出来のように「基準を満たすまで直す」仕事は、Managed Agents の outcomes（別の採点役が基準表で採点し、通るまで直させる）に載せられる
- Google Apps Script は今は使わない。AI の仕事はどれも Cloudflare の中で完結し、毎晩の処理も Cron Trigger で書ける。料金の記録をスプレッドシートで見たい・園にメールで知らせたい、となったときに使う
- 記事とショートの生成を Batch API（半額）に回す。急がない仕事なので向いている
- 本当の料金がたまったら、モデルごとの「上げ直した割合」を見て、Sonnet で足りるか・Haiku に下ろせるかを決める（品質は eval で確かめる）
- 収益の仕組み（有料の相談・園の月額）で、この料金をまかなう。収益の設計は今回の提出の外（`decision.md` の 11/07）
