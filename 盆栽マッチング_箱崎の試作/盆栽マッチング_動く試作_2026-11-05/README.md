# 盆栽マッチング（試作）

海外で盆栽を学びたい人と、日本の盆栽職人を、AIでつなぐスマホ向けのアプリの試作です。
Built with Claude: Japan 2026（オンラインハッカソン）に向けて作っています。

## 解きたい課題
海外では盆栽の人気が高まっている一方、日本では職人の後継者が減っています。海外の人と職人の間には、次の3つの壁があります。

1. **探せない**：海外の人は、日本の職人をどう探せばよいか分からない
2. **言葉**：日本語と盆栽の専門用語が、お互いの壁になる
3. **知ってもらえない**：職人は忙しく、発信に手が回らない

## できること（動く機能）
| 機能 | 画面 | 中身 |
|---|---|---|
| 職人を探す | 18・13 | 知りたいことを母語で書くと、合う職人が理由つきで出る |
| 相談する → 職人が答える | 03 → 22 → 04 → 05 | 写真と母語で相談すると、職人には盆栽の言葉の日本語で届く。職人は話すか写真に線を引いて答え、AIが相手の言葉に意訳し、もう一度AIが職人の言葉とずれていないか見直す。用語に触ると「意味」と「なぜそうするか」が開く |
| 撮るだけで投稿 | 17 | 写真か動画から、英語・スペイン語・中国語の投稿の下書きを作る。スマホの共有画面から Instagram・X などに職人が自分で投稿する |
| 職人の紹介ページ | 19 | 話した内容から紹介ページの下書きを作り、職人が確かめて登録する |
| 学ぶ・用語集 | 10・11 | 盆栽の歴史と育て方、用語の解説 |

- 合言葉を知っている人だけが開けます。開いたあと「職人として／海外の人として」を選んでログインします
- 職人には自分宛ての相談だけ、海外の人には自分が出した相談だけが見えます
- AIの答えは、職人が確かめてから相手に届きます。AIが勝手に職人の言葉として送ることはしません
- 見本の職人（松風 清・楓 ゆき・岩井 正道）は架空の人物です

## 使った技術
- Node.js（手元の Node.js 26 で動作を確認）。画面は HTML と JavaScript
- Claude API（`@anthropic-ai/sdk`）。AIへの指示は `AIへの指示と答えの形.mjs`
- 盆栽の用語集（日本語と英語）：`用語集.json`

## 動かし方
くわしくは [動かし方.md](動かし方.md) を見てください。

```
npm install
cp .env.example .env
chmod 600 .env
npm start
```

- `.env` に鍵を入れないと、記録しておいた見本の答えで動きます（料金はかかりません）
- 鍵や合言葉は `.env` にだけ書きます。`.env` は GitHub に上げません
- 開くページ：http://127.0.0.1:8787/
