## 5. プロジェクト概要（必須・500字以内）
このプロジェクトは、世界の人に「日本といえば盆栽」と思ってもらうための一歩として、海外の愛好家が日本の盆栽園の親方に、言葉の壁を越えて教われる窓口をつくるものです。

2023年の報道では、香川県で輸出用の盆栽を作る農家が増える一方、出荷量は約10年で4割ほど減りました。海外の愛好家が求めているのは日本の職人の知恵だと考えています。でも日本の盆栽園の海外向け添削には、スタッフが訳す先行例があり、訳す人の手が空くまで届くのを待つことになります。

Engawa では、持ち主が写真と自分の言葉で相談すると、園の弟子が日本語で下書きし、親方は一言を足して印を押すだけです。先行例と違い、訳すのは親方が育てる用語集を通した AI で、確かめと印は親方が受け持ちます。「軒下になおして」は、一般の翻訳では "repair" になることがありますが、Engawa では「軒下へ移す」という意味で届きます。送る前には訳を日本語に戻し、親方が自分で確かめます。AI は職人の代わりに答えず、引用が本当に職人の言葉かを照合します。届いた手紙は木ごとの記録に積み重なります。月額は園と職人に入る設計です（いまは見本）。

## 8. 使用した Claude の製品・機能（必須・複数選択）
- Claude Code（デスクトップアプリ）：設計・実装・3D・動画・検品のすべて
- Claude API（`claude-opus-5-5`・構造化出力）：相談の聞き返し、職人向けの要約、弟子の下書きと親方の一言を手紙にする（引用の照合つき）、記事、ショートの台本、AI 窓口

  - サブエージェント：検品役（kenpin）と調べもの役

## 9. 開発中に一番詰まった場面
【要確認：本人の言葉で書き直す。下は候補】

**候補A：iPhone で動画が再生されなかった**
- ①作ろうとしたもの：記事から、解説動画の「その樹種の秒」へ飛んで再生できるようにする
- ②どう指示したか：「スマホでも見たい」と伝えた
- ③何が起きたか：パソコンでは再生できたが、iPhone の Safari では動画が始まらなかった。手元の試験用サーバーでも再現しなかった
- ④期待との違い：「動画を置けば、どこでも再生できる」と思っていた。実際には、Safari は動画の一部だけ（Range）を求めていた。配信側は丸ごと返していたため、再生されなかった
- ⑤どう対処したか：Claude Code が原因を Range の扱いに絞り込み、Worker で 206（一部だけを返す）に対応させた。あわせて、無い動画を HTML として返していた所を 404 に直した

**候補B：方言の「なおす」が "repair" に訳される**
- 一般の翻訳では毎回 "repair" になった
- そこで、用語集に「直訳だとこうなる（まちがいの例）」と「意味」を両方持たせた
- 訳した文を日本語に戻して見せ、職人自身が確かめる流れにした
- 引用が本当に職人の言葉に含まれているかを、サーバー側で照合するようにした
