# 盆栽マッチング 動く試作の動かし方（2026-11-05）

このフォルダで、次を実行します。`node_modules` がなければ、先に `npm install` を1回だけ実行します。

```
npm start
```

開くページ: http://127.0.0.1:8787/index.html

## AIのつなぎ方（3通り）
| 起動のしかた | 動き | 費用 |
|---|---|---|
| `npm start` | 記録しておいた見本の答えを出す。入れた内容は答えに反映されない。そのことは `?demo=1` を付けて開いたときだけ画面の下に出る（ふつうに開くと出ない） | かからない |
| `AI_MODE=claude-code npm start` | この端末でログイン済みの Claude Code で動かす。発表の練習向け | Claude Code の使用枠を使う |
| `.env` に鍵を入れて `npm start` | Claude API で動かす。公開するならこの形 | 使った分の料金がかかる |

鍵は `.env`（GitHub に上がらないファイル）にだけ書きます。コマンドに直接打つと、ターミナルの履歴に残るので打たないでください。
`.env` の作り方は下の「人に使ってもらう形で公開する」の1を見てください。
スマホから試すときは `HOST=0.0.0.0` を足します。声の入力は、ブラウザの決まりで https か localhost でしか動きません。
相談や投稿は `データ/保存データ.json` に残ります。消すと最初の状態に戻ります。

## 見本の答えの撮り直し
`BONSAI_RECORD=（保存先.json）` を足して AI につないで起動すると、AIの答えがそのファイルに残ります。よいものを `見本の答え.json` に写してください。

## スマホと声を試す手順（箱崎さんの手で）
**声の入力: Mac の Chrome で試す**
1. このフォルダで `AI_MODE=claude-code npm start` を実行する（本物のAIで動く。Claude Code の使用枠を使う）
2. Mac の Chrome で http://127.0.0.1:8787/21_話すか撮るだけ_1鉢の記録と出品_職人.html を開く
3. 「話す」を押してマイクを許可し、「この木を海外の人に見せたい。売ってもええ」と話す
4. 「これで記録する」を押して、聞き分けられるかを見る

**写真・動画・画面の見やすさ: スマホで試す（自宅など信頼できるWi-Fiだけで）**
1. いったん止めて、`HOST=0.0.0.0 AI_MODE=claude-code npm start` を実行する。同じWi-Fiの人なら誰でも開ける状態になるので、終わったら止める
2. Mac で `ipconfig getifaddr en0` を実行して、出た番号を控える
3. スマホの Safari で http://（控えた番号）:8787/index.html を開く
4. 「職人の画面から体験を始める」から写真と動画を撮り、字の大きさや押しやすさを見る

スマホでは声の入力は動きません。ブラウザの決まりで https か localhost でしか動かないためです。スマホで声を試すには公開の準備が要ります。
試したあとは `データ/保存データ.json` を消すと、最初の状態に戻ります。

## アプリらしい見た目で見るとき（2026-11-06 追加）
- ふつうに開くと、アプリとしての見た目になる。開発用の注記・「仮」の札・見本を入れるボタンは出ない。画面の下には「見本の職人は架空です」の1行だけ出る
- `?demo=1` を付けて開くと、それらが出る（ブラウザを閉じるまで続く）。`?demo=0` で消える
- **デモ動画は `AI_MODE=claude-code npm start` で撮る。** 見本の答えのまま撮ると、何を入れても同じ答え（針金の相談）が返るため、入れた内容と答えが合わなくなる
- 名前・園・数字は架空。動画のどこかで、そのことを一言伝える
- スマホのホーム画面に置くと、アイコン（漆黒の地に金の「盆」）からブラウザの枠なしで開ける
- 職人の「届いた相談」の一覧は 22番。下のタブ「届いた相談」から開く

## 人に使ってもらう形で公開する（2026-11-07 追加）
本物のAI（Claude API）・合言葉・ログインつきで、一時的な https のURLを作る。Mac をつけたままにする。

1. 鍵と合言葉を `.env` に入れて、サーバーを動かす
   ```
   cp .env.example .env
   chmod 600 .env
   open -e .env
   ```
   開いた `.env` の `ANTHROPIC_API_KEY=` と `ACCESS_PASSWORD=` のうしろに値を入れて保存し、次を実行する
   ```
   npm start
   ```
   - `.env` は `.gitignore` で GitHub に上がらないようにしてある。値の入った `.env` をチャット・Slack・画面の録画に出さない
   - 起動の表示に「合言葉の門: あり」と出ることを確かめる。「なし」なら公開しない
   - AIの回数の上限：`AI_DAILY_LIMIT`（全体で1日、既定300回）、`AI_USER_LIMIT`（1人で1日、既定60回）、`AI_IP_LIMIT`（同じ回線から1日、既定120回）。上限を超えると「本日のAIの上限に達しました」と出て止まる
   - 1回の相談でAIを2回（職人向けの言い換え・答えの案）、職人の答えで2回（意訳・見直し）呼ぶ
2. 別のターミナルで、https のURLを作る（Cloudflare のアカウントは要らない）
   ```
   cloudflared tunnel --url http://127.0.0.1:8787
   ```
   出てきた `https://〜.trycloudflare.com` を開く。URLは起動のたびに変わる
3. 開くと合言葉 → 「職人として／海外の人として」を選ぶログイン → それぞれの画面
   - 海外の人：名前と言語を入れる。自分が出した相談だけ見える
   - 職人：見本の職人か、画面19で登録した職人を選ぶ。自分宛ての相談だけ見える
4. 終わったら両方のターミナルで Ctrl+C。URLは止まる

ログインの印の鍵と、AIの回数は `データ/保存データ.json` に残る（GitHub には上げない）。

## 公開前の安全の確かめ（2026-11-07 追加。「Claude Codeで作ったアプリを安全に公開する」Built with Claude Japan 2026 の資料に沿って）
- 鍵が入っていないかの検査：gitleaks（鍵の検出ツール）で、値を伏せて調べる
  ```
  gitleaks dir . --redact
  ```
- 鍵が外に出てしまったら：すぐに Claude Console で鍵を止めて（失効）、新しい鍵を作り直す。GitHub を非公開にしたり、ファイルを消したりするだけでは足りない
- 動画を撮るとき：`.env`・ターミナルの鍵・ほかの人の相談が映っていないか見返す
