## 3. 色

試作は、色を `共通/見た目の決まり.css` の変数（色に付けた名前）にまとめています。`:root` の中の次の値を入れ替えます。**名前は全画面に影響するので変えません。** たとえば `--koke` は「苔」という名前のまま、中身は黒になります。`--ruri`、`--ruri-2`、`--r-pill`、`--display` の4つは新しく足します。

```css
:root {
  --kami: #FFFFFF;      /* 地の色 */
  --kami-2: #F1F1F3;    /* 一段沈んだ面（図の地・パソコンで見たときの外側） */
  --kami-3: #FFFFFF;    /* 浮いた面（入力欄・シート） */
  --sumi: #111113;      /* 文字 */
  --sumi-2: #62626A;    /* 補足の文字 */
  --sumi-3: #6A6A72;    /* さらに弱い文字 */
  --sen: #E2E2E6;       /* 区切りの線 */
  --waku: #8A8A92;      /* 入力欄と枠線のボタンの縁 */
  --koke: #111113;      /* 選んでいるもの・リンク・完了の面（黒） */
  --koke-2: #000000;    /* 黒いものを押したとき */
  --koke-usu: #F1F1F3;  /* うすい面（知らせの地など） */
  --kin-moji: #FFFFFF;  /* 黒や瑠璃色の上の文字 */
  --kin: #111113;       /* 確かめた印・職人の名。金色をやめて黒にする */
  --ruri: #1E5FBF;      /* 新規：主役のボタン */
  --ruri-2: #174C99;    /* 新規：主役のボタンを押したとき */
  --r: 14px;            /* 角の丸み（カード・入力欄・吹き出し） */
  --r-s: 8px;           /* 角の丸み（写真・札） */
  --r-pill: 999px;      /* 新規：丸い形（ボタン） */
}
```

`--shu`（朱）、`--shu-usu`、`--hachi`（鉢）は変えません。朱の役目も今のままで、知らせ、仮の印、注意、図の上の印だけに使います。

文字と背景の明るさの差（コントラスト比。数字が大きいほど読みやすい）を、WCAG（ウェブの読みやすさの国際基準）の計算式で求めました。基準は文字が4.5対1以上、枠が3対1以上です。区切りの線 `--sen` は飾りなので対象外です。

| 組み合わせ | 白の上 | 灰色の面の上 |
|---|---|---|
| 文字 `--sumi` | 18.9 | 16.7 |
| 補足 `--sumi-2` | 6.0 | 5.4 |
| 弱い文字 `--sumi-3` | 5.4 | 4.8 |
| 朱 `--shu` | 6.8 | 6.0 |
| 枠 `--waku` | 3.4 | 3.0 |

主役のボタンの白い文字は、瑠璃色の上で6.1、押したときの色の上で8.3です。朱の面の上の朱は5.7、朱の上の白は6.8です。

**試作には今、木の短い名前を出す場所がありません。** `02_1鉢のページ.html` の見出しは「A black pine in the informal upright style...」という文章です。案2の見た目を出すため、見出しの上に短い名前を足します。今ある見出しと文章は消しません。まず `02` に足し、`00_ホーム_職人と愛好家.html` の木のカードにも足せるか、開発側の今のデータを見て判断してください。

出し分けは、試作に今ある仕組み（`<span class="t">` と `data-l`）をそのまま使います。職人さんの画面は、この仕組みで自動的に日本語になります（`共通/画面の共通の動き.js` の `getLang`）。

```html
<p class="tree-name t"><span data-l="ja">黒松</span><span data-l="en" class="latin">KUROMATSU</span><span data-l="es" class="latin">KUROMATSU</span><span data-l="zh">黑松</span></p>
<p class="tree-name-sub t"><span data-l="ja">KUROMATSU</span><span data-l="en">黒松</span><span data-l="es">黒松</span><span data-l="zh">KUROMATSU</span></p>
```

```css
.tree-name { margin: 0; font-weight: 700; font-size: 2.375rem; line-height: 1.15; letter-spacing: 0; }
.tree-name .latin { font-family: var(--display); font-weight: 400; font-size: 3.125rem; line-height: 1.08; }
.tree-name-sub { margin: 0 0 var(--s3); font-size: 1.0625rem; font-weight: 600; }
```

ローマ字の例：黒松 KUROMATSU、真柏 SHIMPAKU、五葉松 GOYOMATSU、もみじ MOMIJI、皐月 SATSUKI、梅 UME。どれも9文字以内で、1行に収まります。「Small wired conifer」のように長い説明は木の名前の形にせず、今の文字のまま出します。

Anton は Google Fonts で無料公開されている書体で、通信が切れると別の書体で表示されます。デモの前に通信を確かめるか、書体のファイルを `共通/` に置いて読み込む形にしてください。

## 6. ボタンと区切り

- 主役のボタンは、瑠璃色の地に白の文字、丸い形、高さ48px以上
- 主役は1画面に1つを目指す。同時に2つ以上出るときは**機能を減らさず**、2番目以降を枠線だけのボタンにする。主役のボタンの指定が2つ以上あるのは `00`、`03`、`04`、`07`、`08`、`12`、`17`、`18`、`19`、`21`、ログインです。状態で切り替わって同時には出ないものは直しません
- 枠線のボタンの枠は `--waku` にする
- 影は使わない。カードの区切りは余白と `--sen` の細い線で行う
- 下のメニューはアイコンと文字を組にしたまま（`共通/見た目の決まり.css:324` でアイコンを出しています。`:133` の非表示と `:128` の「文字だけ」という説明は古いものです。`:133` は消さずにそのまま、`:128` の説明は書き換えます）。スマホ幅で「届いた相談」「撮って投稿」が2行に折れて下が切れるので、文字を調整する。言葉を変えるときは箱崎さんに確認する

## 7. 写真

- 写真が高級感を大きく左右します。背景がすっきりした、光の向きがそろった写真を使います
- 盆栽は鉢まで写す。文字を写真に重ねない。木の名前は写真の上か下に置く
- 木の一覧は「名前、写真、情報」の順にそろえる
- 職人さんは顔が大きく見える写真を使う。実在の職人さんの写真は本人の許可を取ってから入れる
