# Claude の使い方（Engawa）

審査の「Claude の活用」で見られる3つの点ごとに、実際にやったことを書きます。

## 1. 使う人のための Claude（アプリの中）
Claude は、職人の代わりに答えません。手入れの助言は、職人の言葉からだけ出します（`src/claude.ts` の `RULES`）。Claude が担うのは、言葉を運ぶ所です。

| 場面 | 関数 | Claude がすること |
|---|---|---|
| 相談が届いたとき | `runIntake` | 写真（画像入力）と質問を読む。職人が答えるのに要ることだけを聞き返す。持ち主の土地の気候を、日本の気候に置きかえる |
| 職人に渡すとき | `runBrief` | 職人向けに、やさしい日本語の3行にまとめる |
| 弟子が下書きしたとき | `runLetter` | 弟子の言葉を、持ち主の言葉の手紙にする。用語集の「意味」で訳し、直訳はしない。どの行にも職人の原文を引用し、日本語に戻した文も返す |
| 親方が一言を足したとき | `runLetter` | 親方の一言も同じ仕組みで訳す。親方は、日本語に戻した文を見てから印を押す |
| 職人が何人も答えたとき | `runKnowledge` | 答えを軸（見立て・置き場所・水・肥料…）ごとに並べ、同じ所と違う所を書く |
| 記事にするとき | `runArticle` | 職人の言葉を引用したまま、5つの言葉の記事に組む |
| ショートにするとき | `runShort` | 縦の動画の台本と、Instagram・YouTube・TikTok ごとの文の下書き |
| AI 窓口 | `runHelp` | 用語集と記事だけから答える。自分の木の話は職人へつなぐ |
| （画面から外した）欲しい木・掲示板 | `runWish`・`runTranslate` | コードは残してある |

使い方の工夫
- **構造化出力**：すべての呼び出しを Zod のスキーマで受ける（`messages.parse`）。画面は、決まった形の答えだけを描く
- **作業の重さで effort を変える**：聞き返しや翻訳は `low`、手紙や記事は `medium`
- **止まらない**：サーバー側のフォールバック（`server-side-fallback`）を使う。断られたとき（`refusal`）や出力が無いときは、エラーとして扱う
- **Claude の答えを、そのまま信じない**
  - 手紙の引用が、本当に職人の話した言葉に含まれているかを、サーバーで照合する（`src/index.ts` の `verbatim`）
  - 含まれていなければ、職人の画面に「⚠ 言い回しが変わっています」と出す
- **方言と専門用語**：用語集の「直訳だとこうなる（まちがいの例）」と「意味」を、プロンプトに毎回入れる。職人が用語集を直すと、次の相談からその訳で届く
- モデル：`claude-opus-5-5`

## 2. 作る側の Claude（Claude Code を開発の中心に）
企画の言語化から、設計・実装・3D・映像・検品・公開まで、Claude Code との会話で作りました。

| やったこと | Claude Code の使い方 |
|---|---|
| 企画を言葉にする | 目的・ゴール・やること／やらないことを書き出してから作る。デザインは3案を作って選んだ |
| アプリ | Cloudflare Workers・KV・静的ファイル。Range（206）で動画を返す所まで |
| 記事24本×5言語 | 出典の URL を読んでから、自分の言葉で書く。下調べはサブエージェントに分けて同時に進めた |
| 3D の木8種と動画 | Blender を Python で動かし、木をゼロから組み立てた（`blender/`）。字幕・BGM・組み立ては ffmpeg（`film/`） |
| 確かめる | ブラウザを操作して、10の機能を通しで試した。スマホの幅、iPhone の Safari での動画の再生も見た |
| 検品 | 公開の前に、検品役のサブエージェントが審査と同じ物差しで点数をつけ、90点まで直した |

## 3. 目的に応じた使い分け
| 道具 | 何のために |
|---|---|
| モデル | ふだんの実装は Opus 5.5。最初の検品と、あとから変えにくい決めごとだけ Fable 5.1。くり返しの検品は Sonnet |
| サブエージェント | 検品役（`kenpin`）。記事の下調べ役（何本も同時に） |
| スキル | 自分用に作ったもの：画像づくり、会議の文字起こしからの宿題出し、セミナー録画の回収、引き継ぎ書づくり |
| フック | `PreToolUse` の「守衛」。外への送信・削除・秘密のファイルの読み出しを、実行の前に止めて確かめる |
| MCP | アプリの画面を開いて操作し、確かめる（ブラウザ）。共有ドライブ・Slack への受け渡し |

## 正直に書いておくこと
- セクションの水彩の挿絵（`public/img/`）は、Claude Code から別の画像生成（GPT Image 2）を呼び出して作った
- いまの公開版は API キーを入れておらず、見本の応答で動いている（画面に「見本」と出る）
