## 2. かずき版：画面ごとの棚卸し（20画面）

読み方
- 1枚の `盆栽ゴー/index.html` に20個の `<section class="scr" id="s-...">` がある。クラス `k` が付いたものが職人側、付かないものが相談する人側（`s-welcome` は入口）。

### 4-2. 変わった API
- `GET /api/me`：箱崎版は職人の簡易カードの一覧だけ。かずき版は園（`gardens`）と、人の役割（園主か弟子か）・言語・出身を足して返す。
- `POST /api/login`：職人の新規登録で、園（`store.gardens`）も一緒に作る。紹介文（`bio`）と最初のひとこと（`first_words`）も空で作る（箱崎版では新規登録の職人が出ると「職人を探す」と `/api/match` が止まる不具合があり、11/8 に直したとコードのコメントにある）。言語は8つ。相談する人の印を別の cookie（`bonsai_grower`）にも覚える（職人に切りかえて戻っても前の相談が見える）。
- `POST /api/logout`：相談する人の印の cookie も消す。
- `POST /api/consultations`：宛先が職人から「園」（`garden_id`）に変わった。相談と答えの言葉が同じなら訳さずそのまま届ける（AIを使わない）。見本モードで見本の質問でないときは原文のまま届ける。保存データに `garden_id`・`garden_lang`・`is_sample`・`same_lang`・`untranslated` が増えた。
- `GET /api/consultations`：職人は「自分の園あて」を見る（園主でなくても同じ園の人ならだれでも）。
- `POST /api/consultations/:id/answer`：①`preview: true` で「相手に届く形」を作って `pending_answer` に置く→②`confirm: true` で送る（確かめた版と違うときは送らない）。言葉が同じなら訳さない。逆翻訳の確かめ（reviewAnswer）に確かさが付き、0.8 未満は「人の確かめ」に倒す。答えに `answer_lang`・`same_lang`・`untranslated`・`by`（答えた人）が増えた。
- `GET /api/teachers`・`POST /api/match`・`/api/posts/*`・`/api/trees*`・`/api/teachers*` など箱崎版の残りの経路：サーバーには残っているが、かずき版の画面（`app.js`）は呼んでいない（呼んでいるのは `/consultations`・`/login`・`/me`・`/bonsaigo/*` だけ）。
- 入口（`/`）：箱崎版はログインか自分のホームへ、かずき版は `盆栽ゴー/index.html` へ。`盆栽ゴー/` はログインなしで開ける。

### 4-4. ログイン・本物のAI・安全の設定は、かずき版でも生きているか
`.env.example` に書かれた変数名と、サーバーが読んでいるかを、コードで確かめた（鍵・`.env` の中身は読んでいない。サーバーは動かしていない）。`.env.example` 自体は2つの版で同じ。

| 変数名（`.env.example`） | かずき版 | 備考 |
|---|---|---|
| `ANTHROPIC_API_KEY` | 生きている | あれば本物のAI（`claude-api`）。ないと見本の答え。`AI_MODE=claude-code` も残っている |
| `ACCESS_PASSWORD`（合言葉） | 生きている | 合言葉の門・cookie・「合言葉なしで外から来たら 503」も残っている |
| `AI_DAILY_LIMIT`／`AI_USER_LIMIT`／`AI_IP_LIMIT` | 生きている（中身は `盆栽ゴー_料金の守り.mjs` に移った） | 初期値が変わった：全体 300→200、1人 60→12、同じ回線 120→60。`.env.example` の説明文（「300回・60回・120回」）は古いまま |

そのほかの確認
- ログイン（パスワードなし・署名つき cookie・`HttpOnly`・`SameSite=Lax`）：生きている。役割ちがいのページをホームへ戻す `PAGE_ROLE`、隠しページ `HIDDEN_PAGES` も箱崎版のまま。
